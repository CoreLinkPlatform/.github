# CoreLink Organization Governance Agent Context

This repository is part of the CoreLink product ecosystem and owns public organization-level governance material.

## Canonical context

Organization-level product, architecture, design, terminology, and agent context is canonical in `CoreLinkPlatform/product-planning`.

Read `product-planning/AGENTS.md`, `PRODUCT_ARCHITECTURE.md`, `GLOSSARY.md`, `STANDARDS.md`, and `architecture/repository-map.yaml` before changing cross-repository policy.

## Repository responsibility

`.github` owns organization profile material, public repository governance, contribution/security/support/release policy, maturity guidance, and reusable GitHub templates/workflows where appropriate.

## Boundaries

- Do not place private product plans, customer information, internal architecture details, credentials, or sensitive operational information here.
- Do not duplicate the product roadmap or canonical architecture in this public repository.
- Public policy must not contradict the private canonical product context.
- Keep reusable governance generic enough to apply across repositories unless an explicit exception is documented.
